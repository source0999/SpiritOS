Phase 1
Tighten layout and sizing

Goal:
Make the chat layout feel less oversized and stop crowding the main navbar.

Scope:

reduce visual bulk of the thread rail
increase clean gap between app nav and chat sidebar
slightly reduce overall chat window footprint where needed
ensure rounded edges and inset feel intentional

Why first:
Because spacing/layout affects everything else. If the proportions are off, glass polish won’t land right.

Deliverables

thread rail slightly narrower / better proportioned
main chat area not touching or crowding left structures
better top/bottom breathing room
cleaner floating-card composition
Phase 2
Rebuild the chat sidebar top section

Goal:
Fix the weakest part of the UI right now, which is the top of the chat nav.

Focus:

CHATS header
saved count
New chat button
Folder button
Search field
draft/new chat block

Direction:
Use screen #3 as the structural reference:

cleaner
more minimal
calmer hierarchy
less awkward than the current New chat block

Important:
This should not be a massive redesign.
It should be a focused cleanup so the top of the sidebar feels like a real product UI.

Phase 4

Goal:
Bring in more of the screen #4 liquid-glass feel.

Focus:

buttons
