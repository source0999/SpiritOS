# Internal Dashboard Demo v4 Design Pack

Status: draft Design Vault pack, documentation-only preview

Source card: `data/design-vault/source-cards/internal-dashboard-demo-v4.json`

## Purpose

This pack records the internal SpiritOS dashboard demo v4 design language as reusable design intelligence. It is meant to support future token normalization, preview review, reverse design analysis, and approved Source Proxy implementation proposals.

## Contents

- `notes.md`: raw design language notes
- `tokens.raw.json`: manual raw token inventory
- `tokens.json`: normalized draft token model
- `theme.css`: preview-only CSS variable aliases
- `components-map.json`: conceptual component mapping
- `reference/`: placeholder for approved reference screenshots
- `generated/`: placeholder for generated preview screenshots
- `match-report.json`: not-run visual verification scaffold

## Approved Use

This is an owned/internal SpiritOS source. The current approved use mode is `internal-exact`.

Allowed:

- exact extraction for SpiritOS design-system planning
- token analysis
- internal design pack preview documentation
- future proposal evidence through Source Proxy approval

Not allowed in this pack:

- automatic app UI writes
- runtime imports from Design Vault
- Scout auto-promotion into coding context
- crawler or autonomous discovery behavior
- external brand, logo, copy, image, or paid asset copying

## Preview Guidance

This pack does not create a preview route. Until a later approved increment creates a preview surface, review the pack through the markdown, JSON, and preview-only CSS files.

Any future live preview must:

- use approved source-card metadata
- stay separate from production UI until approved
- avoid importing `theme.css` into app code without Source Proxy approval
- record screenshots under `reference/` and `generated/`
- update `match-report.json` after capture
