# ADR 0005: Extract Fold7 later

Decision: Fold7 remains in SpiritOS during Campaign 1 and moves to a sibling repository with a real remote later.
Reason: extraction is unrelated to the current authority and provenance gates.
Consequences: no Fold7 move or topology redesign in this campaign.
Campaign 2 dependency: a separate approved extraction plan.
Revision condition: current security or deploy boundaries prove impossible without extraction.
