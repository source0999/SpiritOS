contracts: `packages/contracts/schemas/coding/extended-lane-contracts.v1.json`.

apply, review, verification, anti-cheat, and evidence lifecycle.

Every retained production row has a versioned input, output, failure, acknowledgement,
and evidence contract. `RuntimeLaneBoundary` rejects outputs that lack a compatible
consumer acknowledgement and consumption record. Provider-only and test-only rows
are non-selectable by `selectable_extended_lanes`.

Required per-lane fields are input schema, output schema, failure schema, timeout,
retry, fallback, applicability, consumption acknowledgement, observability, evidence,
and migration requirement; the runtime catalog is the executable source of truth.
