## Evidence vocabulary

- `VERIFIED FACT`: directly established by repository, Git, or file evidence.
- `REPRODUCED BEHAVIOR`: directly observed in a controlled command or test.
- `DOCUMENTED_NOT_RUNTIME_PROVEN`: stated in code/docs but not proven on the selected runtime.
- `INFERENCE`: a bounded conclusion from cited evidence.
- `RECOMMENDATION`: a proposed decision, not current authority.
- `BLOCKER`: a condition that prevents live qualification or adoption.
