# Minimum Architecture

Minimum architecture reuses current SpiritOS components: one canonical /coding task entry, one task/trace identity, existing long-running task and Cartographer state as global workspace, existing workflow event ledger as typed causal events, existing central gate evolved into structured decisions, Obsidian retrieval extended to approved writeback, Mac and Dell workers integrated through explicit approval envelopes, and existing verifier/repair machinery made decisive for productive truth.

Not included without Plan 0.5 approval: a second orchestrator, second policy engine, second event ledger, second UI shell, or major framework migration.
