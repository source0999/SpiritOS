# Human Review Checklist

## Prompt Voice

- [ ] No diagnostic user prompts.
- [ ] No lane names in user prompts unless natural to the task.
- [ ] No "prove/test/show trace" language in user prompts.
- [ ] Prompts trigger real work products.

## Battery Quality

- [ ] Enough research prompts.
- [ ] Enough patch prompts.
- [ ] Enough ambiguous daily-driver prompts.
- [ ] Not too much domain overlap.
- [ ] A6 has explicit no media/Jellyfin mutation boundary.
- [ ] B8 tests honest refusal / no weakening.

## Execution Safety

- [ ] Stage-by-stage human review.
- [ ] Max 3 auto-fix attempts.
- [ ] No Plan 4.
- [ ] No media/Jellyfin mutation.
- [ ] No new parallel harness.
- [ ] No fake GO.

## Grading

- [ ] Explicit per-prompt expectations.
- [ ] Research materially changed output.
- [ ] Same-trace consumer evidence.
- [ ] Policy/recovery/repair consumer evidence.
- [ ] Failure buckets.
