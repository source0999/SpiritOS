## Research Pack: Local Media Metadata Cleanup Tools for SpiritFlix

### Recommendation

For cleaning up messy file names in your SpiritFlix library without directly modifying Jellyfin configurations or media files, **TinyMediaManager** appears to be the most suitable open-source tool. It is specifically designed for this purpose and has been highlighted by users in the SpiritFlix community as a "game-changer."

### Evidence Used

The following findings from Reddit discussions directly inform this recommendation:

* **r/jellifin - Reddit | What media management software do you guys use?**: This thread explicitly mentions **TinyMediaManager** as a tool for quickly cleaning up messy file names in a Jellyfin library.
* **Fast way to clean up file names?**: This Reddit thread also strongly recommends **TinyMediaManager** for its ability to load folders as data and perform metadata cleanup.

The context of the SpiritFlix application code (`src/components/spiriitflix/SpiritFlixApp.tsx` and `src/lib/spiriitflix/jellifin-client.ts`) indicates that the application interacts with Jellyfin via a client library. However, the request specifically prohibits modifying Jellyfin configurations or media files, making a direct integration with a media manager like TinyMediaManager through the application itself unlikely. Therefore, a standalone tool is the appropriate solution.

### Plan

1. **Research TinyMediaManager:** Visit the official website ([https://www.tinymediamanager.org/](https://www.tinymediamanager.org/)) to understand its features, installation process, and usage instructions.
2. **Install TinyMediaManager:** Follow the installation guide for your operating system.
3. **Configure TinyMediaManager:** Point TinyMediaManager to the folders containing your SpiritFlix media files.
4. **Run Cleanup:** Utilize TinyMediaManager's features to rename and organize your media files based on its configured rules.

### Limits

* **No Direct Integration:** This solution does not involve any direct integration with Jellyfin or SpiritFlix configurations or media files. It relies on a standalone application to perform the cleanup.
* **Potential for Errors:** While generally reliable, metadata cleanup can sometimes result in errors or unexpected outcomes. It's recommended to back up your media library before running any cleanup tool.
* **Manual Configuration:** TinyMediaManager requires some manual configuration of naming rules to effectively clean up your specific file names.

### Next Handoff

The next handoff should involve the user installing and configuring TinyMediaManager on their system, pointing it to their SpiritFlix media folders, and initiating the cleanup process. Once the cleanup is complete, the user can verify the results within their SpiritFlix library.
