# Mid-Plan Compression Contract

Every phase evaluates ceremony-to-implementation ratio, evidence budget, new canonical-route value, duplicate architecture, repeated fix cycles, human intervention count, and unconsumed output count.

Triggers: evidence limits exceeded, two increments add no new live capability, one integration has three NEEDS_FIX cycles, new abstraction overlaps existing machinery, two unplanned Britton stops, evidence-only commits exceed implementation commits, output remains unconsumed after two increments, or a parallel UI/API/state engine/event ledger/gate appears.

Allowed decisions: `CONTINUE`, `COMPRESS_CURRENT_PHASE`, `MERGE_INCREMENTS`, `RETIRE_DUPLICATE_PATH`, `ROLL_BACK_PHASE`, `RETURN_TO_PLAN_0_5`, `STOP_FOR_BRITTON`.
