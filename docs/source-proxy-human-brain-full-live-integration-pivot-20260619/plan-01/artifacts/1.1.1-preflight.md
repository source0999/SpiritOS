# 1.1.1 Preflight

Decision-bearing path:

```text
/v1/tasks/long-running/{task_id}/execute-approved
-> source_proxy/approval/gate.py execute_approved_action
-> source_proxy/tasks/long_running.py execute_approved_long_running_task
-> central_gate_check("apply", run_id=...)
```

`/v1/decisions/route` was not used as decision-bearing proof.

Storage surface: existing long-running task SQLite store. It already persists task records and JSON columns, so the causal seam adds only `causal_events_json` to `long_running_tasks`.

No standalone event service, orchestration engine, database, framework, workflow engine, or parallel state engine was added.
