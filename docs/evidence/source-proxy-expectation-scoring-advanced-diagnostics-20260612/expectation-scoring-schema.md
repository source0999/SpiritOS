# Expectation Scoring Schema

The scorer is an additive evaluator over evidence and runtime results. It separates route safety, artifact creation, model authorship, browser openability, functional behavior, intent fit, usability quality, context/search discipline, model-lane discipline, safety boundary, and final product verdict.

Runtime GO, file creation, preview opening, static DOM, and model self-report are non-pass signals. Browser behavior and evidence integrity decide whether a product can be PASS.
