# Root-Cause Matrix

Date: 2026-06-13

This matrix was built from the locked 10d/10e reports before the stabilization patch. The goal is to fix general generation and bounded repair behavior, not to weaken scoring or hard-code locked prompt strings.

| Failure family | Affected prompt ids | Current observed before/after behavior | Likely system cause | Proposed generic fix |
| --- | --- | --- | --- | --- |
| `timer_no_visible_change_after_start` | 10d-01, 10e-01 | 10d before and after Start both show `25:00`; Stop later changes to `24:59`. 10e before and after Start both show `Tea Steep Timer / Start Timer`. | Generation prompt and behavior contract say visible time should change, but do not strongly require JS interval/state mutation tied to Start. Repair packet can also lose useful expected metadata. | Strengthen timer contract/model instructions to require local interval/state mutation, visible tick text after Start, optional Stop freeze, optional Reset initial state. Include expected/probe metadata in repair packet. |
| `route_blocked_no_preview` | 10d-03, 10e-03 | 10d model authored `index.html`, `styles.css`, `script.js`, but route blocked because task resolved as real-repo target-unresolved. 10e model authored `src/components/SunriseMidnightModeToggle.js`, also blocked with no preview. | Generic disposable resolver recognizes some toggle terms as app-ish but not browser-UI-ish; standalone color/mode/toggle/flipper prompts can fall through to clarification/blocking. | Fix generic disposable artifact resolver so standalone browser-viewable theme/color/mode/toggle/flipper widgets route to a disposable static UI artifact with safe model-authored paths. |
| `player_control_no_visible_state_change` | 10e-06 | Before and after click both show `Radio Show Player / Play`. | Generation instruction does not explicitly require play/pause/next controls to mutate visible state for player-family artifacts. Repair packet missing metadata can hand off before a local repair attempt. | Strengthen player contract/model instructions to require visible status/label/track changes on play/pause or next/skip. Ensure repair packet carries expected behavior and primary bucket. |
| `password_no_visible_strength_text_change` | 10d-09, 10e-09 | Weak and strong inputs produce identical visible text. | Generation prompt can create static input/check UI without local input event handling and strength feedback mutation. Repair attempts may be weak or metadata-incomplete. | Strengthen password/passphrase contract/model instructions to require local input listeners and visible weak/medium/strong feedback changes. Include observed weak/strong values in repair prompt. |
| `drawing_canvas_no_pixel_change` | 10d-10 | Canvas exists, bounding box exists, mouse drag does not change pixels. | Generation can create static canvas markup without pointer/mouse drawing handlers. Repair output was free-floating HTML without a path-bound action. | Strengthen drawing contract/model instructions to require pointer/mouse handlers that mutate canvas pixels. Strengthen repair prompt output contract toward path-bound WriteFile/file blocks while preserving HANDOFF for free-floating code. |
| `notes_saved_status_without_note_text` | 10d-08 | After Save, body text only adds `Note saved successfully`; the typed note text does not appear. | Generation can treat saved status or localStorage-only persistence as success without visible note/card/list output. | Strengthen notes/memo contract/model instructions to require the typed text remain visible after add/save/edit. |
| `repair_free_floating_code_no_path_action` / `repair_handoff_missing_probe_metadata` | 10d-01, 10d-09, 10d-10, 10e-01, 10e-06, 10e-09 | Some repair packets hand off for missing probe metadata; other repair attempts return code blocks without path/action and stay HANDOFF. | Browser probes often provide `expected` as a string while repair packet code only reads dict metadata; repair prompt allows path-bound actions but does not provide a crisp output schema/example up front. | Accept string expected text as repair metadata, include primary failure bucket/observed before-after/allowed files in packets, and make the repair prompt explicitly require either Source Proxy WriteFile JSON or `<file path="...">` blocks. |
