# Cartographer Routing Ownership

Cartographer is prepared as the eventual owner for model lane inventory, context source selection, worker eligibility, verifier requirement, dirty-tree awareness, cost and privacy classes, approval gates, performance evidence, promotion/demotion status, and known failure modes.

Current state is preview-only. Source Proxy can produce a routing preview object, but Cartographer does not start workers, call models, write memory, or override Qwen as primary coder in this task.
