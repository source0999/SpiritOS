# Gemma/Hermes Sidecar Scope

Hermes is represented as a future verifier/critic sidecar. Gemma is represented as a future intent/context/spec/verifier sidecar. Both are preview-only in this foundation.

They cannot edit files, execute actions, call providers, mutate app state, write memory, declare success without evidence, or provide hidden benchmark-specific hints. Any live use requires separate operator approval and evidence-driven promotion.
