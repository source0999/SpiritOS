# Repomix Outputs

Generated context packs are written to the repository root.

For the Source Proxy minimum context pack, open:

- `repomix-output.source-proxy-min.xml` - LLM upload file
- `repomix-output.source-proxy-min.ast.xml` - AST mirror
- `repomix-output.source-proxy-min.headroom.xml` - Headroom review copy

These XML files are ignored by Git and may be hidden by the file browser when ignored files are hidden. If you cannot see them, open the repo root folder `/home/source/SpiritOS-cleanup-20260621` or use the terminal path printed after `npm run context:source-proxy-min`.
